# Student Management System - Python

This project is developed as a part of Python Developer Internship at YuvaIntern.

## About Project
This system helps to manage student details like Name, Roll No, Marks easily without paper registers.

## Features
- Add Student
- View All Students
- Search Student by Roll No
- Delete Student
- Exit

## How to Run
1. Download main.py
2. Open in VS Code
3. Run: python main.py
4. Choose option 1 to 5
